# Optional PlayOnline sign-in

Offhand can replay a sequence you teach it for each character. Manual PlayOnline login remains available. Offhand signs in only when you press the sign-in button, and stops after sending Connect once. Choose your character in FFXI as usual.

1. Give the character the same label in Offhand and in the PlayOnline Member List. Choose Save password on Offhand's main screen and save the password for that character.
2. Launch through Offhand. At the Member List, choose Teach path. Choose Teach next POL step and hover over the control shown in the prompt. The first three steps select the member, choose Log In, and open the Square Enix Password field. The fourth records the left edge of the empty typing field. Wait for the result after each step.
3. Return to Member List and choose Replay and fill password. When the typing panel is filled, choose Teach confirmation and Connect and hover over the round confirmation button. Click that button manually after Offhand records it. Keep the diagnostic open and teach Connect on the next screen.
4. On a later launch, start at the Member List and press Sign in beside the launch controls. Keep PlayOnline visible and leave the pointer still. Offhand checks each taught control before clicking. Use the manual login if a layout, dialog, update, or challenge interrupts replay.

Passwords are stored in Windows Credential Manager for the current Windows user. Offhand reads the credential to type into the tracked PlayOnline window. It does not include passwords in character exports or diagnostic logs. Local path files contain window titles, coordinates, dimensions and small grayscale samples. Keep those files local. Use PlayOnline sign-in settings to replace or forget a credential. Forget credentials before renaming or removing their character. The original locally taught pilot paths remain readable when the character label matches.

Use the same window size and profile you taught. An unexpected or mismatched screen stops the run. Enter one-time codes manually if PlayOnline requests them. If a fill is interrupted, clear the field before retrying. Offhand is an unofficial tool. See Square Enix's published PlayOnline rules for third-party software.

If the run stops, read the last completed step and use **Continue in PlayOnline**. If Offhand reports that Connect was sent, check the PlayOnline result before starting a new attempt.
